A note on timing

SEO results usually build over 3–6 months. These two months lay the foundation: tracking, fixes, the right pages and the first links. The goals in section 02 measure progress you can see in that window, such as pages indexed, impressions and technical scores. Revenue targets come after a month of real data.

03 · Week 0 · 15–18 October

Set up every tool before changing anything

Without these, no change can be measured. Most need only an account and a DNS record or a line of code. The client must first grant access to the domain registrar (DNS), Vercel, Shopify admin and the Google account.

Google Search Console
  • Add a Domain property for quinthome.in, verified by DNS TXT record. It covers www, non-www, http and https.
  • Submit https://www.quinthome.in/sitemap.xml
  • Request indexing for home, /range and the 6 diffusers
  • Record the baseline: Pages report, queries, Core Web Vitals, manual actions
  • Add the agency and client users
Google Analytics 4
  • Create a property (India time zone, INR) and a web stream for www.quinthome.in
  • Install through next/script in app/layout.tsx, with the ID in an environment variable
  • Send e-commerce events from the existing Pixel hooks: view_item_list, view_item, add_to_cart, begin_checkout, purchase
  • Add generate_lead (B2B form), sign_up (newsletter) and quiz_complete (Find Your Scent)
  • Add payu.in as an unwanted referral, so sales are not credited to the payment page
  • Link GA4 to Search Console; set data retention to 14 months
Bing Webmaster Tools and IndexNow
  • Import the site from Search Console (one click)
  • Submit the sitemap
  • Turn on IndexNow, so new pages reach Bing (and ChatGPT search, which uses it) within hours
Microsoft Clarity (already live)
  • Connect Clarity to GA4
  • Tag sessions by page type: home, category, product, article, checkout
  • Check that checkout fields are masked
  • Save heatmaps for home, /range, the Monolith and /businesses as the "before" picture
Google Merchant Center
  • Create the account; add business details, shipping (₹99, free at ₹5,000+, 3-day dispatch plus 3–5 days transit) and the returns policy
  • Plan a product feed that uses quinthome.in URLs (built in Week 2, ticket T11)
  • Turn on free listings
Google Business Profile
  • Decide what address to show: a public address, or a Mumbai service area with the address hidden
  • Create the profile with name "Quint Home", category, WhatsApp number, website, hours, photos and products
  • Start postcard or video verification (it can take days)

Also in Week 0

  • Keyword data: ask the Semrush account owner to allocate API units to this sub-account. Meanwhile, pull volumes from Google Keyword Planner (free with a Google Ads account).
  • Rank tracking: set up a project for about 80 keywords from section 09, with Google India as the location.
  • Dashboard and speed data: a Looker Studio report combining Search Console and GA4, shared with the client, and a PageSpeed API key for weekly real-user speed data.

Standard for every article

  • 1,000–1,800 words, written for an Indian reader (room sizes in BHK, prices in ₹, monsoon and festive context)
  • Answer the question in the first 2 sentences, then use question-style H2s. A short FAQ block at the end helps AI assistants quote the answer.
  • 2–4 product links, 1 category link and 2 related articles; a named author (the founder or a named team member) with a short bio
  • Original photos with descriptive alt text; a comparison table where it helps
  • Use only facts that match lib/data, the site's single source of product facts, so articles never contradict the shop
  • Don't publish pages that copy named hotels' scents ("Taj scent"). They carry trademark risk. Write about hotel scent as a craft instead.

11 · Newsletter and email

From a sign-up box to automated emails that sell oil refills

Today the footer form only creates a Shopify customer, with no follow-up. Email supports SEO directly: every newsletter sends readers to new articles, which gets them read, shared and linked sooner.

Set-up (Weeks 1–2)

  • Choose a platform. Klaviyo is the strongest for automated flows and reads Shopify customers and orders. Shopify Email is the cheaper, simpler option. The client decides on budget. Emails use a branded template in the site's fonts and colours.
  • Double opt-in with clear consent wording (DPDP Act). Fix the bug where existing customers' consent is not updated.
  • Sign-up points: footer; quiz results ("email me my match"); a checkout opt-in box; the B2B form; a gentle exit pop-up with an incentive the client approves

Risks

  • Diwali timing: pages published after about 25 October are unlikely to rank before 8 November. Diwali sales rely on email, social and the existing guide; the gifting work pays off for the year-end season.
  • Developer capacity: the plan needs about 3.5 developer days a week. If capacity is lower, Weeks 1–3 (tickets T1–T16) keep their priority and Month 2 tickets slip.
  • Data gaps: without Semrush and real traffic data, the keyword priorities are informed judgement. They will be re-ranked at the month-1 review.
  • Indexing speed: Google may take 1–4 weeks to index new pages. The sitemap, internal links and Search Console requests shorten this.
